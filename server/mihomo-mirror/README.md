# Mihomo mirror metadata

This directory tracks only immutable metadata for the unmodified Mihomo files mirrored at:

`https://www.qiuqiuqiu.top/xxx/codex-network/v1.19.30/`

The binary and corresponding source archives are intentionally not committed to this repository. Before deployment, download them from the exact upstream URLs in the manifest and verify every size and SHA-256 value. Mihomo is distributed under GPL-3.0-only; the mirror must keep the license and corresponding source archive available beside the binary.
