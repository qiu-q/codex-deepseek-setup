# Codex + DeepSeek 安装助手流程与彻底清理设计

## 目标

把当前同屏展示所有操作的界面改成真正的三步向导，并新增可审计、可确认的“彻底卸载并清理”功能。用户在任意时刻只看到当前应该完成的动作；每个异步阶段都显示准确状态，成功后自动进入下一步。

## 用户流程

### 第一步：安装 Codex

- 窗口启动后自动检查系统，不要求用户先理解“检查电脑”。
- 未安装时，主按钮为“下载并安装 Codex”。
- 已安装时，显示版本/状态并自动进入第二步。
- 下载和安装使用分阶段状态：检查环境、下载官方文件、校验签名、等待管理员授权、系统部署、当前用户注册、准备 CLI。
- 管理员凭据提示前明确说明“接下来是 Windows 管理员授权，不是 DeepSeek API Key”。
- 官方部署失败后才显示“实验性解包运行”，并单独说明限制。
- 安装完成后隐藏安装警告和进度条，自动进入第二步。

### 第二步：配置 DeepSeek

- 显示三条明确指引：登录 DeepSeek、完成实名并充值、创建 `sk-` 开头的 API Key。
- 保留“打开 DeepSeek 平台”和“打开 API Keys”按钮。
- API Key 输入框与“验证并配置”位于同一页。
- 输入为空、格式错误、余额不可用、网络失败和模型验证失败分别显示可执行的下一步。
- 配置成功后清空输入框并自动进入第三步。

### 第三步：完成

- 显示“Codex 已配置为使用 DeepSeek”。
- 主按钮为“启动 Codex”；成功检测窗口后显示完成状态。
- 提供“关闭安装助手”和次要危险操作“彻底卸载并清理”。

## 状态与界面

`WizardStep` 保持三步，但每一步拥有独立标题、说明、主操作和可见内容。同一时间只呈现一个步骤页。顶部显示 `1/3`、`2/3`、`3/3` 和已完成步骤。底部状态栏显示当前操作或具体失败原因，不再保留与当前步骤无关的旧提示。

所有长操作禁用会改变状态的按钮。进度条只在下载或安装运行期间出现；完成后隐藏，而不是永久停在 100%。

## 安装记录

程序在 `%LOCALAPPDATA%\CodexDeepSeekSetup\install-state.json` 保存不含秘密的安装记录：

- 安装前是否已存在官方 Codex；
- 使用官方部署还是实验性便携部署；
- 下载缓存、便携目录、CLI 副本和凭据助手路径；
- 修改前的 `CODEX_CLI_PATH` 值；
- 是否已写入 DeepSeek 配置；
- 安装助手已知发布文件目录。

API Key 永远不写入该文件、日志或命令行。

## 彻底卸载与清理

用户点击“彻底卸载并清理”后先显示删除预览，明确告知不可恢复，并默认选择“取消”。确认后执行：

1. 关闭 ChatGPT/Codex 进程。
2. 使用受控提权命令移除当前检测到的 `OpenAI.Codex` 用户包和系统预配包。
3. 删除 Windows 凭据管理器中的 DeepSeek API Key。
4. 删除用户级 `CODEX_CLI_PATH`；如果安装记录包含非本助手值则恢复该值。旧版本没有记录时，只在变量指向本助手管理目录时删除。
5. 永久删除整个 `%USERPROFILE%\.codex`，包括配置、插件缓存和会话数据。
6. 删除 `%LOCALAPPDATA%\CodexDeepSeekSetup`、`%LOCALAPPDATA%\Programs\CodexDeepSeekSetup`、本助手创建的 CLI 副本和便携目录。
7. 删除下载缓存、残留请求和安装记录。
8. 主程序退出后，由复制到 `%TEMP%` 的受控清理进程删除安装助手的已知发布文件，再删除临时清理进程自身。

如果安装助手目录包含不属于发布清单的其他文件，只删除已知发布文件并保留目录及未知文件。不会递归删除磁盘根目录、用户配置文件根目录、桌面或任意调用方传入的路径。

当前版本生成的安装记录用于判断来源；针对旧版本安装，确认对话框明确说明“无法确认 Codex 是否原先存在，本次仍将删除检测到的官方 Codex”，用户再次确认后才执行。

## 权限与失败处理

- 移除系统预配包需要一次 Windows 管理员授权；取消授权时不启动后续数据清理。
- 提权进程只接受固定动作和位于受控请求目录内的请求文件；删除目标由代码根据已知系统目录和目标用户 SID 推导，不接受任意删除路径。
- 当前用户凭据和环境变量由当前用户进程处理，避免使用另一管理员账户提权时删除错误用户的数据。
- 任一步失败都保留安装助手并显示尚未删除的项目，允许重试。
- 只有系统包清理和当前用户清理均成功后才启动自删除。

## 测试

- ViewModel 测试覆盖自动检查、三步迁移、按钮可用性、进度条生命周期和失败后的下一步提示。
- 安装记录测试覆盖原值保存、无秘密序列化和旧版本缺失记录。
- 清理计划测试使用临时目录，验证只包含允许路径、未知同目录文件被保留、`.codex` 被完整删除。
- 路由测试拒绝任意路径、错误 SID 和受控目录外请求。
- 包清理测试验证仅调用固定 `OpenAI.Codex` 包名。
- 自删除测试验证等待主进程退出、删除已知文件、保留未知文件并清除临时副本。
- 发布前运行全量测试、Windows x64 发布、ZIP 完整性和哈希检查；最终仍需在 Windows 10 22H2 普通管理员账户上完成一次端到端验证。
