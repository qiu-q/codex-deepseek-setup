# Codex 安装位置、状态检测与可选清理设计

## 目标

让安装助手在启动时识别现有 Codex，允许用户分别选择官方文件下载目录和 Codex 安装磁盘，并提供独立的数据盘点与按项清理界面。默认优先使用可用的 D 盘，但不修改 Windows 的全局“新应用保存位置”。

## 安装与存储

- 官方文件默认下载到安装助手 EXE 同目录下的 `Downloads`；目录不可写时回退到 `%LOCALAPPDATA%\CodexDeepSeekSetup\Downloads`。
- 用户可以在下载前选择任意下载目录。安装助手只把 `ChatGPT-x64.msix`、`ChatGPT-License.xml` 及其临时分片视为自身可删除的下载文件，不递归删除用户选择的目录。
- 官方 MSIX 只能选择 Windows AppX 磁盘，不能选择任意普通安装文件夹。
- 安装磁盘列表只显示已就绪的本地固定 NTFS 磁盘。D 盘满足条件时默认选择 D，否则选择系统盘。
- 官方包先使用现有离线许可证流程完成部署和当前用户注册。目标不是系统盘时，受控提权助手准备 `<盘符>:\WindowsApps` AppX 卷，随后当前用户进程用 `Move-AppxPackage` 仅移动 `OpenAI.Codex`。
- 移动失败不破坏已经完成的安装；界面明确显示“已安装在系统盘，迁移到目标盘失败”，并允许从维护界面重试。
- 实验性解包模式继续使用普通目录，不冒充完整 MSIX 安装。

## 安装状态检测

启动检查返回包名、版本、安装路径、安装盘和安装类型。已安装时仍自动进入 DeepSeek 配置步骤，但窗口顶部持续显示检测结果，并提供“检测与清理”入口。

维护界面可以刷新状态，并对已经安装在 C 盘的 Codex 执行“迁移到 D 盘”。所有包操作都通过 AppX API 或 PowerShell AppX cmdlet 完成，绝不直接修改 `WindowsApps` 内容。

## 数据盘点

仅扫描当前登录用户的已知 Codex 位置，以及全机的 `OpenAI.Codex` 包/预配状态：

- 当前用户的官方 Codex 包及其版本、安装位置；
- `%USERPROFILE%\.codex` 或当前 `CODEX_HOME`；
- `%LOCALAPPDATA%\Packages\OpenAI.Codex_2p2nqsd0c76g0`；
- 本助手管理的 CLI、实验性解包目录、辅助程序、状态和缓存；
- 当前选择的下载目录中的两个官方文件及临时分片；
- `CODEX_CLI_PATH` 与 DeepSeek 凭据是否存在（永不读取或展示 Key 内容）。

每项显示类别、路径/说明、大小、是否需要管理员权限。无法读取的目录显示“大小未知”，不会导致整个扫描失败。

## 按项删除

维护界面用复选框选择删除内容。官方包、用户数据、应用本地数据、CLI/便携目录、下载文件、凭据/环境变量和安装助手自身相互独立。

- `.codex`/`CODEX_HOME`、应用本地数据和安装助手自身默认不勾选。
- 下载文件、助手缓存和助手创建的 CLI 默认勾选。
- 删除前显示最终清单和不可恢复提示。
- 只删除被选择的已知路径或已知文件名；不会扫描或删除其他 Windows 用户配置目录。
- 选择删除安装助手自身时，其他删除全部完成后才启动临时自删除程序。
- 任一项目失败时保留窗口，逐项报告失败项目；成功项目不重复执行。

## 安全边界

- 任意盘符必须解析为已就绪的本地固定 NTFS 卷。
- 提权路由只接受受控请求目录下的 JSON 请求，目标只能是盘符根路径，不能接受任意命令或任意删除路径。
- 永不把 API Key 写入配置、日志、安装状态或命令行。
- 不改变系统全局默认 AppX 卷。
- 不直接删除 `C:\Program Files\WindowsApps` 或其他盘的 `WindowsApps`。

## 验证

- 单元测试覆盖 D 盘优先、回退系统盘、下载目录回退、状态解析、严格盘符校验、盘点范围和选择性删除。
- WPF 启动测试覆盖新增绑定和维护窗口可构造。
- 全量测试和 Windows x64 发布必须通过；实际 AppX 迁移仍需在 Windows 10 22H2 测试机验证。
